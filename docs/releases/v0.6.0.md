Conversa com editar, apagar e chamada 1:1; conta com e-mail; fontes à escolha.

## Novidades

- **Selecionar e copiar** o texto de qualquer mensagem (arraste com o mouse, Ctrl+C).
- **Editar e apagar as suas mensagens.** Passe o mouse numa mensagem sua: o lápis põe o texto no campo (Enter salva, Esc cancela) e a mensagem fica marcada "editada"; o X pede confirmação e apaga para todo mundo, inclusive áudio e arquivo. Só quem mandou pode editar ou apagar.
- **Chamada 1:1** na conversa direta. Quem recebe vê "te chamando" na lista e no topo da conversa, ouve um toque curto (módulo "som da chamada") e atende pelo telefone.
- **Conta com e-mail.** Criar conta pede usuário, e-mail e senha. Quem já tinha conta continua entrando e pode pôr o e-mail no perfil (Perfil → editar → E-MAIL). Entrar aceita usuário ou e-mail, e o campo de senha tem "ver"/"ocultar".
- **Esqueci a senha.** Na tela de entrada, informe o e-mail para receber um código de seis dígitos (vale 15 minutos) e definir a senha nova. Todas as sessões da conta caem.
- **Fontes.** Configurações → fontes: títulos e botões (VT323, Share Tech Mono, Silkscreen, DotGothic16) e mensagens (Geist, Atkinson Hyperlegible, Fira Sans, Lato).
- **Desenhar pela placa de vídeo** virou um módulo. Desligue nas configurações se a tela aparecer deslocada para baixo (acontecia num PC com driver OpenGL ruim); vale ao reabrir o app.

## Avisos

- O envio do código por e-mail ainda não está ligado a um provedor: o código sai no log do servidor (`docker compose -f docker-compose.prod.yml logs server`), com o e-mail da conta. Quem opera o servidor repassa o código à pessoa. Até existir SMTP, trate o log como segredo.
- Apagar uma mensagem remove ela do histórico de todos, sem rastro.
- App antigo num servidor novo continua funcionando para conversar, mas não cria conta (o servidor passa a exigir e-mail).

## Atualizar o servidor

Na pasta do projeto na VPS (as migrações 0010 e 0011 rodam sozinhas ao subir):

```sh
git pull --ff-only
docker compose -f docker-compose.prod.yml build server
docker compose -f docker-compose.prod.yml up -d --no-deps --force-recreate server
```

O instalador do Windows pode ser atualizado pelo fluxo existente do app; a versão portátil usa o novo ZIP.
