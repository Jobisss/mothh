Atividade do Spotify no perfil e ajustes no chat.

## Novidades

- Foto de perfil ao lado do nome no cabeçalho das mensagens. Clicar na foto ou no nome abre o perfil.
- Imagens enviadas no chat deixam de mostrar o nome do arquivo acima da prévia. O nome continua disponível ao abrir ou salvar; outros tipos de arquivo continuam identificados.
- O cartão e a página do perfil mostram título, artista e progresso da música que a pessoa está ouvindo no Spotify, com o toca-discos 3D girando ao lado.
- **Abrir no Spotify** abre a busca pelo título e artista. O Windows não fornece o endereço exato da faixa.

## Spotify no Windows

Abra o Spotify desktop e toque uma música. Não exige conectar conta Spotify nem Premium. A detecção usa os controles de mídia do Windows e atualiza aproximadamente a cada dez segundos. Ao pausar ou fechar o Spotify, a atividade é removida. Em **Configurações → módulos → atividade do Spotify**, é possível desligar o compartilhamento; quem já havia desligado o módulo de música continua com ele desligado.

O recurso exige Windows 10 1809 ou mais novo e o servidor atualizado. Spotify no navegador e detecção em Linux/macOS não estão incluídos nesta versão. Clientes dessas plataformas podem ver a atividade publicada por outras pessoas.

Título, artista e posição são enviados ao servidor e ficam visíveis às pessoas que compartilham uma conversa com você. Não há histórico persistido de músicas, acesso à sua conta Spotify ou transmissão de áudio. Metadados musicais não são E2EE.

## Reprodução compartilhada suspensa

A fila por nome/link e a transmissão musical pelo LiveKit ficam desativadas no aplicativo e no Compose de produção, inclusive se o `.env.prod` antigo habilitava o worker. O provedor de PO Tokens não sobe por padrão. Chamadas e reprodução de áudios enviados no chat continuam disponíveis.

## Atualizar o servidor

Na pasta do projeto na VPS:

```sh
git pull --ff-only
docker compose -f docker-compose.prod.yml build server
docker compose -f docker-compose.prod.yml up -d --no-deps --force-recreate server
```

Se `music-pot` já estiver rodando de uma instalação anterior, pare o serviço sem remover volumes:

```sh
docker compose -f docker-compose.prod.yml --profile music-experimental stop music-pot
```

O instalador do Windows pode ser atualizado pelo fluxo existente do app; a versão portátil usa o novo ZIP. Atualize o servidor para que a atividade apareça entre contas.
