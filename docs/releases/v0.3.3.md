## Como instalar (Windows)

Baixe `mothh-setup-windows-x64.exe` aqui embaixo e rode. Não precisa desinstalar a versão antiga: o instalador atualiza por cima, e o login e as configurações continuam. Feche o mothh antes, ou deixe o instalador fechar.

Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o instalador ainda não é assinado).

Se preferir não instalar, baixe `mothh-portatil-windows-x64.zip`, extraia e abra o `mothh.exe`.

## Novidade

- **Atualização automática**: esta é a última vez que precisa baixar o instalador à mão. A partir desta versão, o mothh instalado checa sozinho se saiu versão nova (ao abrir e a cada 6 horas), baixa em segundo plano e confere o arquivo (SHA-256). No rodapé aparece "▪ v0.x.y pronta [ reiniciar ]": clicar instala e abre de novo; se você só fechar o app, ele instala ao sair. O login continua. Na versão portátil aparece só o aviso, com o link para baixar. A versão atual aparece no fim das configurações.
