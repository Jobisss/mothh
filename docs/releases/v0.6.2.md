Troca de chaves que não trava mais.

## Correções

- **"Trocando chaves..." sem fim.** Só uma pessoa online por vez muda o grupo cifrado de cada conversa. Se ela estivesse com o app travado, ou com o PC dormindo e a conexão ainda aberta, ninguém mais podia agir e as mensagens ficavam presas. Agora o servidor passa a vez a outra pessoa online depois de 20 segundos sem ação, o app pede isso sozinho enquanto tiver mensagem esperando, e uma conexão calada por 90 segundos é derrubada.
- **Aparelho fora do grupo.** Quem reinstalou o app, ou perdeu o estado das chaves, e via "[cifrada: este aparelho não tem a chave desta mensagem]" em tudo, agora volta a entrar no grupo sem depender de uma pessoa específica. As mensagens de antes de voltar continuam ilegíveis neste aparelho (é assim que a cifra de ponta a ponta funciona); as novas abrem.

## Atualizar o servidor

Esta versão muda o servidor. Na pasta do projeto na VPS:

```sh
git pull --ff-only
docker compose -f docker-compose.prod.yml build server
docker compose -f docker-compose.prod.yml up -d --no-deps --force-recreate server
```

O app atualiza pelo fluxo existente; a versão portátil usa o novo ZIP.
